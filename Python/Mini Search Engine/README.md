# Mini Search Engine

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file.

Add your OpenAI API Key.

Add your Pinecone API Key.

Run

```bash
streamlit run app.py
```

Upload at least five PDFs.

Click **Process PDFs**.

Search using natural language.

---

Technology Used

- Python
- Streamlit
- Pinecone
- OpenAI Embeddings
- PyPDF
